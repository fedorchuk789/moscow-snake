# Snake Maps

Змейка по настоящим дорогам Москвы в пределах МКАД: https://snake-maps.ru/

## Источники

- Дорожный граф: © участники OpenStreetMap, ODbL.
- Подложка карты: OpenFreeMap / OpenMapTiles, © OpenStreetMap.
- Поиск адресов: Nominatim (OpenStreetMap).
- Изображения дорожных знаков России: Wikimedia Commons. Для каждого файла в `signs/credits.tsv` указаны исходное имя на Commons и лицензия (CC BY-SA 3.0 / 4.0, CC0 или общественное достояние). Авторы перечислены на страницах файлов: `https://commons.wikimedia.org/wiki/File:<имя файла>`.
